HOW TO ADD YOUR OWN MUSIC
-------------------------
1. Put an MP3 file in this folder.
2. Rename it to:   wedding.mp3
3. Refresh the website. It plays when the guest taps "Tap to open",
   loops, and can be paused with the music button at the top-right.

If no wedding.mp3 is here, the site plays its built-in instrumental tune.

Tips: keep the file under ~5 MB (128 kbps, 2-4 min). Only use music you
have the right to use (e.g. YouTube Audio Library, Pixabay Music, or a song
you've purchased a licence for), especially if the site is public.
